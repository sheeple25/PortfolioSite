- [ ] **Move Traces' charts onto Bklit UI** (`components/charts/`, vendored from the `@bklit` registry — see `components.json`). Bklit is the chart system this site is meant to use: the Figma frame for Traces literally labels the slot "custom bklit UI chart", and the old board build did use it. The live page instead draws its two figures as hand-rolled inline SVG in `app/projects/traces/sections/problem.data.tsx`, because of two real bugs in the registry — both documented in `docs/CASE_STUDY_FORMAT.md` §7:
  1. `BarChart` with `orientation="horizontal"` + `stacked` miscomputes the final segment's width (rendered `x=287.5, width=-32.5`, so 47% of the bar silently didn't draw).
  2. `LineChart` forces a zero-based y-domain for all-positive data (`resolveTimeSeriesYDomain` returns `[0, max * 1.1]`, no floor prop), which flattens the 130–152 MAU series into a straight line.
  Fix both at the source, then swap the bespoke SVG back out. Bklit is re-pullable with `shadcn add`, so check whether upstream has already fixed either before patching locally. Keeping the library is deliberate — it is wanted for future charts, not just this one.
